# Explor Plus: الموقع والمتجر

| الصفحة | لمين | شو فيها |
|---|---|---|
| `index.html` | الكل | موقع الشركة (عربي/إنجليزي)، الخدمات، فورم طلب على واتساب |
| `store.html` | الزباين | حساب برقم الجوال، محفظة وشحن رصيد، شراء واستلام فوري، طلباتي |
| `admin.html` | إنت بس | طلبات الشحن، الطلبات، المنتجات، المخزون، الزباين |

الإعدادات كلها بملف واحد: **`assets/config.js`** (أرقام الواتساب، طرق الدفع، العملة، ربط Supabase).

---

## تشغيل المتجر (مرة وحدة، حوالي 10 دقايق)

1. **اعمل مشروع مجاني** على [supabase.com](https://supabase.com) (New project، واختار منطقة قريبة متل Frankfurt).
2. **قاعدة البيانات:** من القائمة اختار **SQL Editor**، ثم **New query**. الصق محتوى ملف `supabase/schema.sql` كامل واضغط **Run**.
3. **طفّي تفعيل الإيميل:** من **Authentication**، ثم **Sign In / Providers**، ثم **Email**، طفّي **Confirm email** واحفظ.
   (الزباين بيسجّلوا برقم الجوال، والموقع بيعمل إيميل داخلي من الرقم.)
4. **اربط الموقع:** من **Project Settings**، ثم **API**، انسخ **Project URL** و **anon public key** وحطهم بملف `assets/config.js`.
5. **اعمل حسابك:** افتح `store.html` واعمل حساب برقمك.
6. **خلّي حالك أدمن:** ارجع على SQL Editor وشغّل (غيّر الرقم لرقمك):
   ```sql
   update public.profiles set is_admin = true where phone = '0597653989';
   ```
7. ادخل على `admin.html` وضيف منتجاتك ومخزونك. ✅

## الاستخدام اليومي

- **شحن رصيد:** الزبون بيحوّل وبيرفع الإيصال. بتفتح **طلبات الشحن**، بتشوف الإيصال، وبتضغط **موافقة**، والرصيد بينزل فوراً.
- **اشتراكات تلقائية:** من **المخزون** الصق الحسابات (سطر لكل حساب). لما الزبون يشتري، أول حساب متوفر بيتسلّم إله، وما في حساب بيتباع مرتين.
- **خدمات يدوية:** الطلب بيظهر بتبويب **الطلبات**. اكتب اللي بدك يوصل للزبون واضغط **تسليم**.
- **استرجاع:** زر **استرجاع المبلغ** بيرجّع السعر لرصيد الزبون.

## نسي كلمة السر؟

الزبون بيراسلك على واتساب. من **SQL Editor** شغّل (غيّر الرقم وكلمة السر الجديدة):
```sql
update auth.users set encrypted_password = crypt('كلمة_سر_جديدة', gen_salt('bf'))
where email = 'p0590000001@phone.explorplus.app';
```

## الأمان

- الرصيد ما بيتغيّر إلا من خلال دوال بقاعدة البيانات (شراء، موافقة شحن، استرجاع، تعديل أدمن)، والزبون ما بيقدر يعدّله بنفسه.
- الزبون ما بيشوف المخزون، بيشوف بس الحساب اللي اشتراه.
- صور الإيصالات خاصة: الزبون بيشوف إيصالاته بس، وإنت بتشوف الكل.
- الـ anon key عام وآمن يكون بالموقع. **لا تحط أبداً** الـ `service_role` key بأي ملف.
