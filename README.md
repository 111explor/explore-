# Explor Plus: موقع الشركة

موقع **Explor Plus للدعاية والإعلان**: صفحة واحدة بالعربي والإنجليزي، فيها الخدمات العشرة، وفورم بيجهّز طلب الزبون ويبعته على واتساب.

## الملفات
- `index.html`: الموقع كامل
- `assets/`: اللوجو (نسخة فاتحة ونسخة غامقة) والأيقونة

## التعديل السريع (كله بأول الـ `<script>` بآخر `index.html`)
- `WHATSAPP`: رقم الواتساب
- `SERVICES`: الخدمات (عربي وإنجليزي)
- `WORKS`: صور وفيديوهات الأعمال (حطها بمجلد `assets/works/`)
- `REVIEWS`: آراء العملاء الحقيقية

## الطوابع
فيه 3 طوابع للمعاينة: `midnight` (ليلي)، `clean` (فاتح)، `aurora` (أورورا).
بتقدر تجرب أي واحد من الرابط: `?style=clean`، أو من زر "اختر الطابع".

## النشر المجاني
GitHub Pages: من Settings ثم Pages، اختار الفرع `main` والمجلد `/ (root)`.
